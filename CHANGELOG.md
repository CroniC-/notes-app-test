## [1.0.0] - 2026-08-18

### Added

- Initial release of Notes App
- Markdown support (headings, bold, italic, code, lists, links, blockquotes, horizontal rules)
- LocalStorage persistence with auto-save (400ms debounce)
- Folders and tags for organization
- Full-text search across all notes
- Light and dark theme toggle
- Responsive design for mobile and desktop
- Import/export as JSON
- Keyboard shortcuts (Ctrl+N, Ctrl+S, Arrow keys, Enter, Escape)
- Relative timestamps with auto-refresh
- Accessibility features (ARIA labels, keyboard navigation)
- Comprehensive test suite (82 tests)
